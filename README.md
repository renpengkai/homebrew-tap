# renpengkai/homebrew-tap

```bash
brew install --cask renpengkai/tap/smoothscroll
brew install --cask renpengkai/tap/macmonitor
```

| Cask | 说明 |
| --- | --- |
| `smoothscroll` | [SmoothScroll](https://github.com/renpengkai/smooth-scroll-mac)：极小的 macOS 外接鼠标平滑滚动工具 |
| `macmonitor` | [MacMonitor](https://github.com/renpengkai/macmonitor)：极小的菜单栏系统监控，CPU / 内存 / 功率 / 温度 / 风扇控制，适配液态玻璃 |

各 Cask 由对应的 `update-*` 工作流每 6 小时同步一次上游最新 Release，也可以手动触发。
